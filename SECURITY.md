# Security Policy

## Reporting a vulnerability

We support GitHub's private vulnerability reporting workflow. To report a security issue, go to **Repository → Security → Report a vulnerability** and submit the details through the private form instead of opening a public issue. Reports are handled as quickly as possible.

Please do not disclose the details of a vulnerability publicly before we have had a chance to address it.

## About this repository

FogSea Survival is a text-based survival strategy game (Vue 3 + TypeScript monorepo) playable on Android and the web.
