# 《全民求生：迷雾降临》项目文档

> 一款**文字抉择式全民求生**单机离线手游 —— 全球迷雾降临，你只有一间破木屋、一份新手礼包，和一个别人没有的天赋。

## 当前状态（v0.1.2）

✅ **双端可玩**：

| 端 | 状态 | 入口 |
|----|------|------|
| Web | 可玩 | `cd web && npm install && npm run dev` → http://localhost:5173，或双击根目录 `启动游戏.bat` |
| Android APK | 可玩 | Capacitor 打包：`npm run build && npx cap sync android && gradlew assembleDebug`（详见 [docs/04 §9](docs/04-安卓构建与发布.md)） |
| Cocos Creator 3.8 | 源码可构建 | 原生路线，见 docs/02、docs/04 |

核心系统全部落地：22 天赋流派 · 118 条手写选择事件 + 204 条程序化探索事件 · 4 档宝箱 · 3 场天灾 · 14 结局 · 5 线技能树（15 节点）· 场景剧本引擎（朵朵线/老K线/救援线/结晶真相线 各 8 幕）· 动态世界 · 合成/交易/成就/设置。共享逻辑层 27/33 文件为纯 TypeScript，Cocos 与 Web 双端复用；质量门禁：单测 55 用例 + Web jsdom 全流程冒烟 + 双端 tsc 0 错误 + 蒙特卡洛数值校验（死亡率 40~60% 达标）。

## 仓库结构

```
assets/scripts/     游戏逻辑（core 核心 / systems 系统 / ui Cocos界面 / data 数据定义）
assets/resources/   Cocos 动态资源（含合成音效 WAV）
web/                Web 端：Vite + DOM 版界面 + jsdom 冒烟测试 + Capacitor 安卓工程
tools/              单元测试（55 用例）与蒙特卡洛数值模拟器
docs/               策划 / 架构 / UI / 构建发布 四份文档
启动游戏.bat         Windows 一键起 Web 版
```

### 开发与测试命令

```bash
cd tools && npm test && npm run sim      # 共享逻辑单测 + 数值分布校验
npx tsc -p tsconfig.game.json            # 共享层类型检查（仓库根目录）
cd web && npx tsc --noEmit && npx vitest run   # Web 类型检查 + 全流程冒烟
```

## 核心设计原则

## 里程碑总览（业余时间个人开发约 8 周）

```
W1-W2  原型验证   ── 核心循环：探索/黑夜/死亡判定 + 20 个事件
W3-W4  内容填充   ── 天赋10种、宝箱4档、60+事件、3场天灾、庇护所升级
W5     氛围包装   ── 世界频道文案池、音效BGM、动效、新手引导
W6     数值调优   ── 模拟器跑分布，死亡率/存活天数校准
W7     安卓适配   ── 打包签名、真机矩阵测试
W8     测试上架   ── TapTap/好游快爆提审
```

## 核心设计原则

1. **内容即壁垒**：框架简单，竞争力在事件文案质量；全部 JSON 配置驱动，扩内容不改代码。
2. **爽文节奏**：新手礼包必出货、宝箱有品质惊喜、天赋带来流派差异——把网文的"爽点密度"做进游戏。
3. **氛围即美术**：系统面板风 + 世界频道群像 + 迷雾遮罩，用排版和文案营造沉浸，绕开美术短板。
4. **完全离线**：无任何 SDK、零权限申请，审核最快路径；数据只存本机。
