# 04 - 安卓构建与发布指南

> 版本 v2.0（迷雾降临版）| 定位：**完全免费 · 无广告无内购 · 完全离线 · 零 SDK**
> 该定位是个人开发者的最优路径：合规最简、审核最快、维护成本最低。

---

## 1. 本机构建环境

| 组件 | 要求版本 | 说明 |
|------|----------|------|
| Android Studio | Hedgehog (2023.1.1)+ | 编辑导出工程与签名打包 |
| JDK | **17**（必须） | Cocos Creator 3.8 Gradle 插件要求 |
| Gradle | 7.5+（模板自带 wrapper） | 不手动升级大版本 |
| NDK | r23~r25 | 仅引擎运行时需要（本项目无自研原生代码） |
| CMake | 3.22.1 | 同上 |

确认 `JAVA_HOME` 指向 JDK17；SDK Manager 勾选 API 34/35 Platform 与 Build-Tools。

## 2. Cocos Creator 构建面板参数

`项目 → 构建发布 → Android`：

| 参数 | 取值 | 备注 |
|------|------|------|
| 游戏名称 | 全民求生：迷雾降临 | |
| 包名 | `com.<你的缩写>.fogdescends` | 上架后不可改，慎重 |
| Target API Level | **34**；出海 Google Play 用 **35** | 2026 年起 Google Play 新应用强制 35 |
| Min API Level | **21**（Android 5.0） | 覆盖率 >99% |
| ABI | `arm64-v8a` + `armeabi-v7a` | 追求极致包体可只留 arm64 |
| 渲染后端 | 仅 GLES3 | 降低兼容性风险 |
| MD5 Cache / 加密脚本 | 关闭 | 无热更需求 |

构建后用 Android Studio 打开 `build/android/proj`。

## 3. 签名配置

### 3.1 生成 keystore（一次性，双备份，丢失无法更新应用）

```bash
keytool -genkeypair -v ^
  -keystore fog-descend.keystore ^
  -alias fog -keyalg RSA -keysize 2048 -validity 10950 ^
  -storepass <强密码>
```

### 3.2 Gradle 接入（密码不入 git）

`gradle.properties`（本机/CI 私有）：

```properties
FD_STORE_FILE=D:/keys/fog-descend.keystore
FD_STORE_PASSWORD=********
FD_KEY_ALIAS=fog
FD_KEY_PASSWORD=********
```

`build.gradle`：

```groovy
android {
    signingConfigs {
        release {
            storeFile file(FD_STORE_FILE)
            storePassword FD_STORE_PASSWORD
            keyAlias FD_KEY_ALIAS
            keyPassword FD_KEY_PASSWORD
        }
    }
    buildTypes {
        release {
            minifyEnabled false    // 引擎产物混淆收益低风险高
            shrinkResources false
        }
    }
}
```

出包：`gradlew assembleDebug`（测试）/ `gradlew assembleRelease`（正式，Google Play 用 `bundleRelease` 出 AAB）。

## 4. 权限声明（本项目为最理想情况）

**完全离线 + 零 SDK = `AndroidManifest.xml` 零权限申请。**

- 无 INTERNET：商店"隐私"栏直接填"不收集任何信息"，审核最快；
- 若未来加统计 SDK 再补 `INTERNET` + 同意后延迟初始化；
- **禁止顺手添加**定位/存储/相机——单机游戏加这些必被驳回或举报。

## 5. 包体优化清单（目标 ≤ 50MB，实际可做到 ~35MB）

| 手段 | 收益 | 做法 |
|------|------|------|
| 纹理 ASTC 6x6 | 大 | 图标+UI 合并 Auto Atlas，图集数 ≤4 |
| 音频压制 | 中 | 音效 mp3 mono 96k；BGM 单曲 128k 循环，总量 ≤6MB |
| 引擎裁剪 | 中 | 功能裁剪剔除 3D 物理/Video/Web/Spine(未用) |
| 字体子集化 | 中 | 思源黑体常用 3500 字 ≈1.2MB |
| 资源审查 CI | 小 | 脚本报告未引用资源 |

验收：release 包大小 + 冷启动 <3s + 内存峰值 <150MB（Android Profiler）。

## 6. 中国区合规要点（免费纯离线版的最简路径）

1. **APP 备案**：上架国内商店前置条件；备案号在商店后台与游戏内"关于"页公示。
2. **隐私政策**：仍需提供文本（声明数据仅存本机 localStorage、无网络请求）；首次启动弹窗确认一次即可。
3. **软件著作权**：华为/小米/OV 等传统商店必需；**TapTap / 好游快爆 对个人开发者更友好，作为首发渠道**。
4. **版号问题**：本作免费无内购，以免费独立游戏类目在 TapTap/好游快爆发布通常无需版号；若未来上传统安卓渠道或加变现，先确认最新口径。
5. 内容自审：末日生存题材避免血腥直描文案与自杀细节暗示（结局 E07 文案已按此规范），分级建议 12+。

## 附：常见问题

**Q：构建报 "Unsupported class file major version"**
JAVA_HOME 未指向 JDK17，修正后 Invalidate Caches 重启。

**Q：真机白屏**
渲染后端被改为 Vulkan 或纹理格式不支持，回退 GLES3 + ASTC 默认档。

**Q：TapTap 审核意见"请补充隐私政策"**
即使零联网也必须在游戏内可查看隐私政策全文，并在首次启动弹窗确认。

**Q：想以后加广告怎么办？**
架构已预留（EventBus 埋点位置见文档02 §5）；届时需补 INTERNET 权限、SDK 延迟初始化、隐私清单更新三件事。
