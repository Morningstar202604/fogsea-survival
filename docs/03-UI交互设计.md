## 1. 界面流程总图

```
对局主界面 GameView ◀══════════════════════════╗

   ├─▶ 背包抽屉 / 制作面板 / 庇护所面板           ║
```

### 2.2 天赋抽取 TalentDraw（开局仪式感）

- 进入后先展示 3 张背面卡牌（"命运三选一"，实际从 10 池抽 3 再选 1，**给玩家选择感**——比直接随机 1 张体验好且实现成本相同）；
- 点选一张 → 翻转 500ms → 金光揭示 `【每日提示】` + 效果说明 + 流派标签；
- 未选两张翻开展示"错过的可能"（重开钩子）；
- 底部按钮「带着它醒来」→ 苏醒演出。

### 2.3 新手礼包拆包

全屏深色，中央包裹图标抖动 → 点击撕开 → 物品条目逐条 300ms 间隔弹出：

```
【叮！获得 黑面包 ×2】
【叮！获得 饮用水 ×2】
【叮！获得 木材 ×10】
...
```

每条配短促音效（音高递增），最后一条停顿后世界频道首波刷屏淡入。

### 2.4 对局主界面 GameView（最重要）


**状态规则**

- 属性 <30 图标红闪+心跳音；变动飘字 `+40💧` / `-15`；
- 状态效果小图标排属性栏右端，点击弹 tooltip；
- 天气图标随天气切换；夜间整屏叠加深蓝暗角滤镜。

### 2.5 世界频道（两种形态）

**气泡形态**（默认）：主界面叙事区下方半透明单行，新消息从底部滑入顶掉旧消息，最多停留 8 秒。不打断操作。

**全屏形态**（点击气泡展开）：

```
┌────────────────────────┐
│ ◀ 返回   🌐 世界频道      │
├────────────────────────┤
│ [等风来]:第14天还活着…    │
│ [干饭第一名]:谁卖盐？     │
│   └ 你: 我出两个罐头换    │   ← 仅展示，无真输入
│ [理性分析]:别信保平安的   │
│ ...                      │
├────────────────────────┤
│ 输入框(置灰):"幸存者无法发言"│ ← 暗示世界观：你只能旁观
└────────────────────────┘
```

> "能看不能说"是刻意设计：强化孤独感 + 免去聊天内容审核风险。

### 2.6 事件抉择弹窗 EventDialog

```
┌────────────────────────┐
│ ███ 半透明黑遮罩 ███      │
│ ┌────────────────────┐ │
│ │ ⚠ 危机 · 屋顶脚步声  │ │ ← 类型徽章(危机红/日常灰/
│ ├────────────────────┤ │   夜间紫/探索绿)
│ │ 正文打字机输出…       │ │
│ ├────────────────────┤ │
│ │ A 抄起铜剑冲出去      │ │
│ │ B 裹紧被子装睡        │ │
│ │ C 【提示】朝烟囱扔石子 │ │ ← T01专属项，金色描边
│ │ D (置灰)开灯查看 🔦   │ │ ← requires不满足:灰+图标
│ └────────────────────┘ │
└────────────────────────┘
```

- 弹窗期间模态锁底层；
- 选择 → 按下态100ms → 结果替换正文（打字机重放）→ 飘字 → 800ms 收起；
- 连锁事件无缝接续；**不显示概率数值**。

### 2.7 开箱演出

事件结果为宝箱时插入专用小演出：箱子按品质着色(木白/铜绿/银蓝/金紫) → 抖动 → 光柱 → 道具逐条弹出（同新手礼包组件复用）。金箱额外全屏闪白+稀有音效。**整套演出 ≤3 秒，可点击跳过。**

### 2.8 黄昏抉择弹窗

D4 起 AP 有剩余时触发：

```
「太阳正在下沉，迷雾开始变浓了。」
 A 回家（安全）
 B 再探一轮（收益+50%，危险↑）   ← 高危时此选项红字+第六感警告
```

### 2.9 天灾横幅与结算

- 预警：倒计时条变红闪烁 + 全屏横幅一次`【系统】寒流将于2天后抵达`；
- 当日：主界面顶部常驻灾害名条；世界频道联动刷屏；
- 扛过后：`【系统】你熬过了寒流` + 世界频道报平安文案，情绪释放点。

## 3. 全局交互规范

| 项 | 规范 |
|----|------|
| 点击反馈 | 可点元素缩放0.95 + click.mp3 |
| 打字机 | 25字/秒，设置可调快/中/慢/瞬时；点正文跳过 |
| 转场 | 页面200ms淡入淡出；对局→结算600ms黑场 |
| 震动 | 死亡/危机事件/天灾来袭轻震30ms（可关） |
| 返回键 | 对局中→"已自动保存，确定退出？"二次确认；其余=pop栈顶 |
| 杀进程恢复 | 从最近阶段开头续玩（阶段粒度存档保证一致性） |

## 4. 视觉风格指引

- **基调**：冷灰蓝底 + 迷雾白渐变，UI 呈"系统面板"质感（细边框、方括号标签、等宽数字）；
- **色彩即信息**：普通白/精良绿/稀有蓝/史诗紫四色贯穿物品、宝箱、事件徽章；危险唯一高饱和红；
- **氛围演进**：随天数 UI 底色从灰蓝 lerp 到深黑紫（4 组色调插值），压迫期自然感到窒息；
- 字体：标题34px粗 / 正文26px / 注释20px（720p 下），思源黑体子集；
- 图标：game-icons.net 统一 2px 描边处理；属性图标形状差异+数字常驻（色盲安全）。

## 5. 安卓适配要点

| 问题 | 方案 |
|------|------|
| 刘海/挖孔 | `view.setSafeArea`，状态栏整体下移 |
| 手势条 | 行动点指示器底部留 24px |
| 折叠屏展开 | FIXED_WIDTH 两侧铺背景延伸图 |
| 分辨率回归 | 720×1280 最小档 + 20:9 主力档 |
| 夜间游玩 | 提供全局暗色已是默认；无强白屏页面 |
