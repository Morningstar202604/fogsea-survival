# 02 - 技术架构设计

> 版本 v2.0（迷雾降临版） | 引擎：Cocos Creator 3.8.x LTS | 语言：TypeScript strict

---

## 1. 技术选型与理由

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 引擎 | Cocos Creator 3.8.x LTS | 中文生态最好、2D UI 成熟、安卓导出稳定、包体小 |
| 语言 | TypeScript strict | 配置表结构强类型校验，策划配错在加载期暴露 |
| 架构风格 | 数据驱动 + 单例系统层 | 玩法全靠 JSON，代码只是"解释器"，内容扩展零代码改动 |
| 网络 | **无（完全离线，零 SDK）** | 免费无广告定位 → 零权限、合规最简、审核最快 |
| 存档 | sys.localStorage + 版本迁移 | 单机足够；预留文件存档升级位 |
| UI 框架 | 自写轻量 UIManager（界面栈） | 页面 <12 个，不引第三方框架 |

**素材管线（零美术约束）**：

- 图标：game-icons.net SVG 批量下载脚本 → 转 PNG 128px 入图集；
- UI 九宫格：Kenney UI Pack 直接导入，SpriteFrame 设置 sliced；
- 字体：思源黑体子集化（游戏用字约 3500）≈1.2MB；
- 音频：Kenney 音效包 + freesound CC0，mp3 mono 96kbps。

## 3. 启动流程

```
Main.scene onLoad
  └─▶ GameManager.init()
        1. ConfigLoader.loadAll()        // 全部 JSON + 引用完整性校验
        2. SaveManager.init()            // 迁移旧档到最新 schema
        3. AchievementSystem.attach()    // 全局档案挂载
        4. UIManager.push(HomeView)
```

配置校验失败（事件引用不存在物品/天赋 ID 等）→ 开发构建直接抛错并打印 JSON 路径。**宁可启动失败也不带病上线。**

## 4. 核心接口定义（data/ 目录，节选）

```ts
// ===== TalentDefs.ts =====
export interface TalentDef {
    id: string;                    // 'T01' ~ 'T10'
    name: string;                  // 【每日提示】
    desc: string;
    rarity: number;                // 展示星级
    hooks: TalentHook[];           // 声明式效果钩子
}
export type TalentHook =
    | { type: 'lootMult'; mult: number }                 // T02 产出×2
    | { type: 'nightRiskFactor'; factor: number }        // T03 夜间风险×0.5
    | { type: 'dirtyConsumeFactor'; factor: number }     // T04
    | { type: 'craftCostReduce'; n: number }             // T05
    | { type: 'combatBonus'; pct: number }               // T06
    | { type: 'bagCapacityAdd'; n: number }              // T07
    | { type: 'chestUpgradeChance'; pct: number }        // T08
    | { type: 'giftEveryNDays'; n: number }              // T09
    | { type: 'revealHintDaily' }                        // T01
    | { type: 'dangerWarn' };                            // T10

// ===== EventDefs.ts =====
export type StatKey = 'hp' | 'hunger' | 'thirst' | 'sanity';
export type EventType = 'daily' | 'crisis' | 'explore' | 'night' | 'story';

export interface EffectPayload {
    hp?: number; hunger?: number; thirst?: number; sanity?: number;
    gainItems?: { id: string; count: number }[];
    loseItems?: { id: string; count: number }[];
    addStatus?: string[]; removeStatus?: string[];
    setFlags?: string[]; nextEvent?: string; endingId?: string;
    unlockLocation?: string;
    chat?: { poolId: string };       // 触发世界频道插播（v2 新增）
}

export interface EventOption {
    text: string;
    requires?: {
        items?: { id: string; count: number }[];
        talent?: string;             // 天赋专属选项（v2 新增）
        stats?: Partial<Record<StatKey, { op: '>=' | '<='; value: number }>>;
    };
    results: ResultBranch[];
}

export interface EventDef {
    id: string; title: string; text: string;
    type: EventType; pool?: string[];
    weight: number; once?: boolean; cooldownDays?: number;
    conditions?: {
        dayMin?: number; dayMax?: number;
        flags?: string[]; notFlags?: string[];
        stats?: Partial<Record<StatKey, { op: string; value: number }>>;
        items?: { id: string; count: number }[];
        weathers?: string[]; disasterActive?: string;
    };
    options: EventOption[];
}

// ===== ChatPoolDefs.ts（世界频道，v2 新增）=====
export interface ChatMessage { nick: string; text: string; }
export interface ChatPool {
    id: string;                     // 'phase_1_3' / 'disaster_cold' ...
    weight: number;
    dayMin?: number; dayMax?: number;
    messages: ChatMessage[];
}
```

## 5. 单局运行时模型 RunModel

```ts
export interface RunState {
    version: number;
    seed: number;                     // 本局种子（复现轨迹）
    day: number;                      // 1 起
    phase: 'morning' | 'daytime' | 'dusk' | 'night';
    apLeft: number;
    talentId: string;                 // 本局天赋（v2 新增）
    stats: Record<StatKey, number>;
    statMax: Record<StatKey, number>;
    statuses: { id: string; remainDays: number }[];
    inventory: { id: string; count: number }[];
    bagCap: number;                   // 12 或 18(T07)
    shelterLevel: number;             // 1~3
    facilities: string[];
    unlockedLocations: string[];
    locationCooldowns: Record<string, number>;
    flags: string[];
    firedEvents: string[];
    weather: string;
    disasterState: { nextId: string; dueDay: number; activeToday: boolean };
    chatCursor: Record<string, number>;   // 各文案池已消费下标（防重复）
    sanZeroStreak: number;                // 连续崩溃天数
}
```

**UI 只通过 EventBus 监听变更刷新，禁止直改 RunModel：**

```
'stats:changed'{key,delta,newValue}   'inventory:changed'
'status:add/remove'                   'event:show'{eventDef}
'event:result'{branch}                'day:advance'{newDay}
'disaster:incoming'{id,dueDay}        'chat:new'{msg}      ← v2
'talent:drawn'{talentId}              'run:end'{endingId}
```

## 6. 关键算法

### 6.1 天赋抽取（开局）

```ts
const t = RNG.weightedPick(configs.talents);   // 均匀权重
RunModel.talentId = t.id;
EventBus.emit('talent:drawn', t);
```

所有数值型钩子在对应系统的计算点统一查询 `TalentSystem.has('T02')` / `factorOf(hook)`，避免散落特判。

### 6.2 宝箱掉落（LootSystem.openChest）

```
品质判定：roll < P(gold)?gold : roll < P(silver)?silver : ...（基础 4/13/28/55）
T08：先以 20% 概率整体上调一档再进池
产出 = 从该品质 loot_table 抽 1~2 组，T02 产量 ×2
```

### 6.3 事件抽取（EventEngine.pick）

```ts
candidates = allEvents.filter(e =>
    e.type === poolType &&
    !firedOnce.includes(e.id) &&
    cooldownOK(e) &&
    checkConditions(e.conditions, run));   // 含 talent/weathers/disasterActive
if (empty) return FALLBACK_EVENT;
weightedPick(candidates, w => e.type === 'crisis' ? e.weight * (1 + run.day * 0.08) : e.weight);
```

### 6.4 结局判定链（EndingSystem.evaluate，夜晚末尾调用，短路求值）

```
1. run.endingId 已被事件直设        → 用之
2. hp <= 0                          → 按致死原因细分 E08~E12
3. sanZeroStreak >= 3               → E07
4. 无线电已组装(事件直设 flag)       → E01
5. day > 15                         → 有信号堆?E03 : 有信号枪?E02 : E04
```

### 6.5 世界频道滚动器（WorldChannelSystem）

```ts
tick(dt: number): void {
    this.timer += dt;
    if (this.timer >= this.nextInterval()) {       // 90~180s 随机
        this.timer = 0; this.nextInterval = rand(90, 180);
        const pool = pickWeighted(activePools());  // 阶段池+联动池
        const msg = pool.messages[this.cursor[pool.id]++ % pool.messages.length];
        EventBus.emit('chat:new', msg);
    }
}
// 节点插播：DisasterSystem/EventEngine 通过 emit('chat:inject') 强制插入指定池消息
```

### 6.6 可种子化随机数（RNG.ts，mulberry32）

seed 记入存档；客服/调试可凭 seed+局号完整复现玩家轨迹。

## 7. 存档方案

| 键 | 内容 | 写入时机 |
|----|------|----------|
| `qs_run` | RunState JSON | 每次阶段切换后（防杀进程丢进度） |
| `qs_global` | 成就、结局图鉴、累计统计、设置 | 变更即写 |

版本迁移：`while (v < SAVE_VERSION) data = MIGRATIONS[v](data)`；解析异常 → 备份原串到 `qs_run_bak` 再开新档。轻量防篡改：属性总和校验和，失败提示"存档异常"。

## 8. UI 层规范

- UIManager 页面栈 `push/pop/replace`，转场 200ms 淡入；
- 弹窗类挂高层级节点+遮罩拦截穿透；
- 文案全部走 `I18N.key` 表（首发仅中文也强制 key 化）；
- 叙事文本统一 `Typewriter` 组件（25字/秒，点击跳过）——文字游戏手感核心；
- 世界频道是常驻小组件而非页面：主界面右缘半透明气泡流，点击展开全屏频道页。

## 9. 性能预算

| 项 | 预算 | 手段 |
|----|------|------|
| DrawCall | < 30 | 图集 ≤4 张、Label 系统字体缓存 |
| 内存峰值 | < 150MB | 配置 JSON 全量 <600KB；纹理 ASTC |
| 包体 | ≤ 50MB | 见《04-安卓构建与发布》裁剪清单 |
| 冷启动 | < 3s 中端机 | Main.scene 极简 |

文字类游戏性能风险极低，质量重心在文案量与数值手感。

## 11. 代码规范要点

- TS `strict: true`；JSON 解析边界允许 any 但必须立即经 validator 收敛；
- 系统 API 返回新值或 EventBus 广播，UI 禁止直改 RunModel；
- 命名：文件 PascalCase / 变量 camelCase / 常量 UPPER_SNAKE；
- 提交信息：`feat(event): 新增夜间事件池 5 条`；
- 分支：main 稳定 / dev 集成 / 功能分支 PR。
