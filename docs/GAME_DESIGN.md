---

## 1. 产品愿景与定位

一句话：**"把《全民迷雾求生》式的求生流爽文，做成每天 10 分钟的文字生存 roguelite。"**

- 品类：文字抉择生存（Text-based Survival）× 系统流养成
- 对标体验：求生流网文的"系统面板 + 天灾压力 + 排行围观"三件套
- 目标用户：番茄/起点求生流读者、文字放置/抉择手游玩家
- 核心情绪曲线：**匮乏的焦虑 → 搜刮的爽感 → 天灾前的备战紧张 → 挺过去的成就感**

### 三大设计支柱
1. **不进则退**：天灾倒计时 + 排行榜下滑，玩家永远有"再撑一天"的理由
2. **看得见的成长**：属性/物品 Lv/基地/技能/排名全部面板化、可感知
3. **选择的重量**：天赋不可换、专精不可逆、支线互相挤占——build 由选择铸成

---

## 2. 核心循环（Core Loop）

```
 新局：抽天赋（三选一，S/A/B 分级）
   ↓
 每日循环：查看面板/背包 → 行动（场景选项/事件/探索/交易）
   → 结束今日 → 每日结算（签到→消耗→收入→事件→天灾→排行榜→成就）
   ↓
 压力事件：天灾预警(3-7天) → 天灾降临(强制事件) / 兽潮(战斗)
   ↓
 中期扩张：基地升级 → 技能专精(30点, 不可逆) → 支线剧情(角色羁绊/救援/结晶)
   ↓
 终局：D80 迷雾之主倒计时 → 终局事件 → 14 种结局之一 → 图鉴解锁 → 新周目(天赋重抽)
```

单局时长目标：15-40 天（30-60 分钟）；日活钩子：连续签到、排行榜周报、结局收集。

## 3. 系统规格（Systems Spec）

### 3.1 开局天赋（已实现 v0.9 → v1.0 保留）
- 9 天赋，S×3 / A×4 / B×2，稀有度加权三选一（S:1 A:2 B:3），可"换一批"
- 一次性加成 + `talent_*` 持久 flag（引擎各挂点读取）
- 扩展方向 v1.1：天赋池扩到 15+，S 级加入"独oday一"词条（同局不可重复抽取）

### 3.2 每日签到补给（v1.0 新增）
- 连签天数 `runStats.signinStreak`，断签（跳过结算不累计）
- 奖励表：D1 木材×10 / D2 食物×8 / D3 水×8+理智+5 / D5 金属×5 / D7 木矛×1+食物×15（周奖励循环）
- 播报格式：`【签到】连续第 N 天：获得 …`

### 3.3 排行榜压力（已实现）
- 162 人确定性排名：`81 − (基地×6 + 世界等级×10 + 幸运/3 + 物资种类)` + 天数×1.2 下滑
- 每 3 天播报 + 对手点名（RIVAL_NAMES 池）；≤#3 触发欢呼播报
- v1.1：结算页展示最终排名 + 与历史最佳对比

### 3.4 物品自动升级（已实现）
- 使用（消耗）物品累积熟练度，10×Lv 升级；「强化万物」天赋双倍
- 经济联动：商人收购价 ×(1+0.1×(Lv−1))
- v1.1：Lv≥3 的武器/工具给数值加成（攻击/防御/探索）

### 3.5 战斗遭遇（v1.0 本轮接入）
- 触发：runDaily 无事件日，D≥3 起 `15% + 世界等级×5%` 概率遭遇
- 怪物池：`getAvailableMonsters(day)` 按天数解锁，兽潮日必遭遇
- 回合：攻击/防御/道具(占位)/逃跑；会话存 `state.combat`，UI 自动切战斗页
- 结算：掉落 `result.loot` 入背包；`xpGained` 换技能点（1/10）；击杀计入 `runStats.kills`
- 败北：生命≤0 → 死亡结局（与饥饿死亡同轨）
- v1.1：防御动作减伤实现、道具使用（消耗品回血）、兽潮波次连战

### 3.6 基地 / 技能 / 经济 / 天灾（已有，规格落地）
- 基地 5 级 12 建筑；技能三分支 + 30 点专精不可逆；经济积分+商人+动态定价
- 天灾 5 档（D10/20/35/45/60）+ 世界等级 5 档（D7/15/30/50/80）强制事件已全部内容化

### 3.7 成就系统（v1.0 新增）
- 首批 12 枚：生存类（活过 7/30/60 天）、成长类（基地3级/技能专精/物品Lv3）、内容类（救援线完结/见真相/结盟）、挑战类（排名≤10/击杀20/无伤兽潮）
- 存储 `meta.unlockedAchievements`（跨周目持久）；达成即【成就】播报
- v1.1：成就点数 → 解锁初始天赋池扩展（meta 驱动的 meta-progression）

### 3.8 死内容处置（v1.0 执行）
- `storyline_v2/alliance/crystal.ts` 归档至 `content/_archive/`（git 保留可追溯）
- 其中优质概念（迷雾真相=观察者/联盟政治/结晶修仙）吸收进 v1.1 内容线提案

## 6. UI/UX 规格（安卓优先）

- 信息架构：ResourceBar 常驻（资源+排名）→ 7 页签（剧情/基地/背包/技能/战斗/市场/推进）→ 底部"结束今日"主按钮

- 天赋三选一弹层：S 金/A 蓝/B 绿描边，移动端单列
- 触控目标 ≥44px；viewport-fit=cover 已启用；v1.1：安全区 padding、横屏适配、启动屏/图标替换
- 文案规范：系统播报用【】前缀（签到/排行榜/成就/物品升级/世界升级/天灾），叙事正文用「」对话

## 7. 技术架构约定（Architecture Notes）

- monorepo：`packages/core`（纯 TS 引擎，零 DOM 依赖）+ `apps/web`（Vue3 测试壳）+ Capacitor 安卓壳
- 引擎新增系统一律：独立模块 + types.ts 挂 state + save.ts 旧档兼容 + vitest 覆盖
- 内容校验：validate.test.ts 为合入门禁（next 可达/资源键/物品 id/文本泄漏）
- 版本基线：**2.0.2**（root/core/web/gradle 统一）；此后 semver：内容=minor、系统=major 里程碑
- 已知技术债：STORY_TRIGGERS 双轨待合并、full.ts 待拆分、dist 出 git、use_item 实现
